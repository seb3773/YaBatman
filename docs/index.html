Key Capabilities & Architecture

🛡️
Hardware & BIOS Mitigations
Fixes problematic laptop modern standby (s2idle) by automatically putting hardware into deep minimal power mode before suspend.
⚡
Zero-Sudo Privilege Separation
High-performance root daemon (yabatmand) communicates via secure Unix sockets, eliminating sudo or polkit prompts.
📊
Detailed Battery History
Interactive usage and discharge graphs, charging state timeline, wear level calculation, and automatic 72h 100% calibration alerts.
🎬
Custom Sleep Animations
Smooth full-screen transition animations (Vintage TV-off, Circle Wipe, Fade) before entering suspend or shutdown.
⚙️
CPU Governor & Frequency Caps
Granular CPU governors and custom frequency limits per profile (Eco, Balanced, Performance, Ultra-Eco).
🌙
Built-in Screensavers
Ultra-lightweight native screensavers (Matrix, Starfield, 3D Pipes, Plasma, Photo Slideshow) with zero CPU overhead.
