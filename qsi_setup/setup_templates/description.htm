Welcome to the YaBatman Setup Wizard

YaBatman (Yet Another Battery Manager) is a comprehensive, lightweight battery monitor and advanced power management tool for Linux and the Trinity Desktop Environment (TDE).

Key Features:

  • Dynamic Profiles: Eco, Balanced, and Performance modes for AC and Battery.
  • Hardware Power Controls: CPU governor/frequency caps, webcam unbinding, charge threshold (80%).
  • Graphical History: Track discharge curves and average consumption rates over time.
  • Screensavers & Transitions: Digital/Analog clocks, Matrix rain, photo slideshow, CRT TV turn-off effect.
  • Powernap Mode: Keeps background tasks running without sleep when closing lid on AC.
